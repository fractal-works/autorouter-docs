# AutoRouter for T3 Code

Source: [autorouter.com/integrations/t3](https://autorouter.com/integrations/t3)

Turn T3 Code on in the AutoRouter Mac app and pick AutoRouter for a Codex or
Claude thread. Each turn goes to the model that fits it, on the AI
subscriptions you already pay for first.

**Works in:** T3 Code, on macOS 14 or later. Experimental.

## Set up

1. **Install the Mac app.** [Download AutoRouter](https://autorouter.com/AutoRouter.dmg),
   sign in or create a free account, then connect your plans.
2. **Turn on T3 Code.** Click Enable on T3 Code's row, in setup or in
   Settings, under Apps. This turns on Codex. Turn on Claude Code too for
   Claude threads.
3. **Open or restart T3.** Click Open, or Restart if T3 is running. It opens a
   new thread with AutoRouter selected.
4. **Use your existing Codex.** If T3 signs in to Codex on its own, switch its
   Codex to Use existing CLI. AutoRouter shows you how.

## What changes

- **Nothing new for Codex.** T3 runs Codex from your Codex profile, so the
  change AutoRouter makes there ([Codex setup](codex.md)) covers T3.
  AutoRouter's models come from Codex's own model list.
- **One entry for Claude.** While Claude Code routes through AutoRouter,
  AutoRouter adds itself to T3's Claude custom models in
  `~/.t3/userdata/settings.json`. T3 picks it up without a restart.
- **Turning it off.** T3 Code's row follows Codex, so turning Codex off in
  AutoRouter turns T3 off too. The Claude entry comes out cleanly, and every
  other T3 setting stays.

## Plans

The same as in Codex and Claude Code: their own sign-ins, plus the Claude,
ChatGPT, Grok and Gemini plans you connect in AutoRouter. Models no plan
covers run on credits.

## Limits

- Experimental. T3's other agents, such as Cursor, OpenCode and ACP agents,
  aren't routed.
- A Codex that T3 signs in to itself (Continue with ChatGPT in T3's welcome)
  doesn't read AutoRouter's profile.
- T3 titles each thread with a separate call on its own text model.
- Restart T3 once for Codex, since it reads the profiles when it starts its
  agents. The Claude entry needs no restart.
